========================================================================
ANLEITUNG: LOGOS / BILDDATEIEN AUF GITHUB PAGES HOCHLADEN & EINBINDEN
========================================================================

Diese Anleitung beschreibt, wie du Bilddateien (z. B. Markenlogos) in dein
GitHub-Repository hochlädst und als feste Vorlagen in deinem Sirup-Umrechner
für alle Besucher verfügbar machst.


------------------------------------------------------------------------
SCHRITT 1: BILDDATEIEN IN GITHUB HOCHLADEN
------------------------------------------------------------------------

1. Öffne deinen Browser und gehe auf deine GitHub-Repository-Seite:
   https://github.com/DEIN_BENUTZERNAME/DEIN_REPOSITORY_NAME

2. Klicke oben rechts im Repository-Bereich auf den Button:
   "Add file" -> "Upload files"

3. Ziehe deine Bilddateien (z. B. holy-logo.png, sodastream-logo.png)
   per Drag & Drop in das Feld oder klicke auf "choose your files".

4. Klicke unten auf den grünen Button "Commit changes".

   Hinweis: Die Bilddateien befinden sich nun im selben Ordner wie deine
   "index.html".


------------------------------------------------------------------------
SCHRITT 2: CODE IN DER INDEX.HTML ANPASSEN
------------------------------------------------------------------------

1. Öffne die Datei "index.html" in deinem GitHub-Repository.
2. Klicke oben rechts auf das Stift-Icon ("Edit this file").
3. Suche im JavaScript-Bereich nach dem Feld "DEFAULT_PRESETS".
4. Trage deine Vorlagen mit dem exakten Dateinamen der Bilder ein:

------------------------------------------------------------------------
BEISPIEL-CODE:
------------------------------------------------------------------------

const DEFAULT_PRESETS = [
    { 
        id: 'holy_default', 
        name: 'Holy Kartusche', 
        origRatio: 140,
        targetRatio: 24, 
        volume: 85, 
        logo: 'holy-logo.png' // Exakter Dateiname in GitHub
    },
    { 
        id: 'sodastream_default', 
        name: 'SodaStream Flasche', 
        origRatio: 23,
        targetRatio: 19, 
        volume: 840, 
        logo: 'sodastream-logo.png' 
    }
];


------------------------------------------------------------------------
WICHTIGE HINWEISE
------------------------------------------------------------------------

- Groß- und Kleinschreibung beachten:
  GitHub unterscheidet strikt zwischen Groß- und Kleinschreibung!
  "Holy-Logo.PNG" und "holy-logo.png" sind unterschiedliche Dateinamen.

- Unterstützte Formate:
  Empfohlen werden PNG, JPG oder SVG mit transparentem oder dunklem
  Hintergrund, damit das Logo gut auf dem dunklen Design der App aussieht.

- Nach dem Speichern (Commit):
  Es kann bis zu 1-2 Minuten dauern, bis GitHub Pages die neue Version
  deiner Web-App aktualisiert. Falls sich nichts ändert, lade die Seite
  neu (Strg + F5 / Cmd + Shift + R).
